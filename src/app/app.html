01-Challenge: Regular Functions vs Arrow Functions

1. Research: Differences between Arrow Functions and Regular Functions

A partir del material estudiado en la presentación Clase 01 - JS , identifique las siguientes diferencias:

Característica Regular Functions Arrow Functions
Sintaxis (Syntax) Usa la palabra clave function.
function suma(a, b) { return a + b; }
const f = function(a, b) { return a + b; } 		Usa la sintaxis de flecha => (ES6).
const suma = (a, b) => { return a + b; }
Permite retorno implícito: (a, b) => a + b
Contexto de this Tiene su propio contexto de this dinámico (depende de cómo y quién invoca la función). Puede ser redefinido con bind(), call() o apply(). No tiene su propio this. Hereda el contexto léxico (lexical this) del ámbito exterior donde fue declarada.
Objeto arguments Cuenta con el objeto local arguments, el cual contiene todos los parámetros pasados a la función. No posee el objeto arguments. Para parámetros variables se debe utilizar el operador Rest (...args, visto en slide 19).
Uso como Constructor (new) Puede ser utilizada como función constructora instanciada con new y posee propiedad prototype. No puede usarse como constructora con new (lanza TypeError) y no tiene propiedad prototype.
Elevación (Hoisting) Las declaraciones function nombre() {} son elevadas (hoisted) completamente al inicio del ámbito (slide 11). Al ser asignadas a variables (const / let), no son hoisted y no pueden invocarse antes de su línea de asignación (slide 11).
Métodos en Objetos Recomendadas para métodos de objetos cuando se requiere acceder a propiedades del objeto mediante this (slide 14). No recomendadas para métodos de objetos que dependan de this propio.
